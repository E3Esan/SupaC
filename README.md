## Current project

### SuperNoobCalc

A simple command-line calculator written in C.

It supports:

- Addition
- Subtraction
- Multiplication
- Division
- Error handling for invalid operator input
- Protection against division by zero

The program asks the user for two numbers and a chosen operation, then prints the result.

---

## Run it

Make sure you have a C compiler installed, such as GCC.

```bash
gcc SuperNoobCalc.c -o SuperNoobCalc
./SuperNoobCalc
```
